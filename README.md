# 课程提示词库

面向手机使用的静态网页应用（PWA）。学生填写姓名后，可按课程和类型查找、查看案例图、复制中文模板；教师可逐条新增、编辑、归档，也可导入 JSON。当前内置 **43 条**“动漫3AI数字绘画”模板，其中 **37 条有案例效果图**，六个 IP 展板主题等待教师上传原创素材。

## 先在这台电脑预览

Mac 双击 `启动本地预览.command`；如果系统询问，选择“打开”。浏览器打开 `http://127.0.0.1:8765/index.html`。本地预览要查看案例图，也需把另行交付的 `#imgkey=...` 加到网址末尾。本地地址只能由这台电脑访问；手机和学生需要完成下方的部署。直接双击 `index.html` 通常无法读取 JSON，不是应用故障。

## 一次性公开部署（GitHub Pages）

这套应用没有付费后端、域名或数据库。GitHub Pages 可从**公开仓库**免费托管静态网页。公开仓库中的代码和提示词文本可被任何人查看；案例图文件已加密，仓库里不含原图或解密密钥。学生用教师私发的专属链接自动解锁图片，仍只需填写姓名。**拿到链接的人可以转发并查看图片；这不是严格的账号权限控制。**

1. 准备一个 GitHub 账号，安装官方 GitHub Desktop，或用熟悉的 Git 工具。
2. 将本文件夹（不要只上传 ZIP）建立为一个**公开**仓库并推送。仓库名可自定，例如 `course-prompt-library`。保持 `index.html` 在仓库根目录。
3. 编辑 `src/config.js`，把 `repoOwner` 改为 GitHub 用户名，`repoName` 改为仓库名，`branch` 改为实际分支名（通常是 `main`），提交并推送。**不要把管理密钥填进文件。**
4. 仓库的 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，选择 `main` 和 `/(root)`，保存。等待 GitHub 显示网址，再用手机打开该网址。
5. 从另行交付的 `教师专属图片链接密钥_请勿上传.md` 复制学生链接和教师管理链接，把其中用户名、仓库名换成你的实际信息。**不要把这份密钥文件上传到公开仓库。**教师在管理链接首次打开时，还需输入只授权这个仓库的 GitHub 管理密钥，并设置自定密码。建议在 GitHub **Settings → Developer settings → Personal access tokens → Fine-grained tokens** 创建：只选这个仓库，Repository permissions 中 **Contents: Read and write**。首次连接时同时设置至少8位的本机解锁密码。管理密钥经密码加密后保存在本机浏览器；以后输入自定密码解锁。清除网站数据、换浏览器或管理密钥过期后需重新连接。不要发给学生，也不要放到截图或群聊里。

GitHub Pages 发布后，链接通常形如 `https://用户名.github.io/仓库名/`。学生需使用带 `#imgkey=...` 的专属链接；普通公开链接可浏览提示词，但看不到案例图。应用内使用相对路径，直接放在仓库根目录即可。GitHub 在部分网络环境中的访问速度可能不稳定，正式给全班使用前请用学生的手机网络实测。

## 学生怎么用

1. 打开教师私发的专属网页链接，填入自己的姓名。
2. 选择课程和类型，或直接搜索关键词；点开条目可看效果图和中文提示词。
3. 点“复制提示词”，把【方括号】里的项目资料换成自己的内容。
4. 想放到手机桌面：iPhone 用 **Safari → 分享 → 添加到主屏幕**；Android 用 **Chrome → 菜单 → 添加到主屏幕／安装应用**。若在微信内打开，先用菜单在系统浏览器打开，再添加到桌面。

姓名仅保存在该浏览器的当前会话中，不上传服务器，也不验证身份；它不是正式的登录系统。学生可以不提供手机号、QQ 或微信账号。请勿用该姓名输入作为考勤或作品归属的唯一证据。

## 教师怎么更新

- **逐条新增**：教师管理 → 新增提示词 → 填课程、类型、标题、中文正文；需学生替换的地方写成【字段】；上传 PNG/JPEG/WebP 效果图（单张小于 8 MB）；设为“已发布”并保存。学生刷新页面后可见。编辑、归档同理。
- **案例图加密**：教师必须用带 `#imgkey=...` 的管理链接打开。上传时图片在浏览器中加密，公开仓库只收到加密文件。不要手动把原始图片放进仓库的 `public/examples/`。
- **草稿与归档**：这两种状态不会在学生页面显示，但条目仍保存在公开仓库的 JSON 中。请勿把需要保密的内容写进此库。
- **批量导入**：在教师管理中选“导入 JSON”，文件格式可参考 `src/data/catalog.json`。以 `slug` 为唯一编号，相同编号更新，新的编号新增。导入前先导出备份。JSON 中的图片路径必须指向仓库中已有的 `.enc` 加密图片；新条目可先导入文字，再逐条上传配图。
- **备份**：教师管理 → 导出备份。JSON 包含提示词和图片路径；图片文件仍在仓库中，请同时保留仓库备份。
- **六版 IP 统一规则**：教师管理底部的“IP展板共用要求”只改一次，学生复制六个主题时会自动加入；各主题仍保留自己的排版要求。

更新通过 GitHub 内容接口写入仓库，不需要单独服务器。GitHub Pages 可能需要几分钟重新发布；学生刷新后再看。若提示权限不足，检查管理密钥的仓库范围和 Contents 写权限。
